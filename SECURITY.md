# Security policy

## Reporting a vulnerability

Please report security problems privately and do not open a public issue for them.

Use GitHub private vulnerability reporting on this repository, https://github.com/AproposRobin/VBeef (Security tab,
"Report a vulnerability").

Include what you found, the version (`VisualBeefEditor.exe --version`) and steps to reproduce.

## What happens next

You get an acknowledgement within 7 days and a first assessment within 14 days. A fix ships in a new release; the release
notes describe the problem once users have had time to update. Reporters are credited if they want to be. These are
targets for a small volunteer project, not a service-level agreement.

## Supported versions

Only the latest release is supported.

## Scope

In scope: the editor, the file handling that reads and writes project files, the code generator, and the release workflow
and build scripts. Out of scope: problems in third-party libraries (report them to their authors), and findings that need
an already-compromised PC.
